Запуск проекту:
1) Клонувати проект з github
2) В терміналі Git Bash ввести команду npm install 
3) В терміналі Git Bash ввести команду npm run build
4) Після успішного завершення збірки ввести в терміналі команду: npm run start 
5) Перейти за адресою, яку видасть термінал

Функціонал сторінок

URL - / - сторінка зі списком усіх фільмів,

URL - movies_of_genre/[id] - сторінка зі списком фільмів одного вказаного жанру

URL - moviesCard/[id] - сторінка з описом одного вказаного фільму

URL - MovieSearch/[search] - сторінка зі списком фільмів, знайдених за пошуковим запросом
